Suggestions (optional)
Explore and Near stay need an Anthropic API key to generate suggestions. Everything else works without one. The key is stored on this device only and is never sent anywhere except Anthropic.
—
Get a key at console.anthropic.com — it is a separate account from your claude.ai subscription. Usage is billed to you and each set of suggestions costs roughly a penny. Leave it blank to just use the planner.
